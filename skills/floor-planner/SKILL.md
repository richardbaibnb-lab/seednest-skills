# 平面图转3d图 floor planner

把用户给出的地址、实测房间尺寸和补充要求，落实为用户账户内可继续编辑的 Floorplanner 项目。默认中文沟通。真实几何和采购配置优先，历史案例指导搭配，最终文字说明自主增加了什么。

## 依据与边界

- 尺寸：用户最新明确提供或确认的尺寸优先；realestate.com.au 的2D图仅辅助辨认布局、门窗、房间连接和暂缺尺寸。用户口中的 realesate.com 指澳洲房产网站 realestate.com.au，核对完整地址后取图。
- 家具与摆件：用户本次明确指示优先于飞书（新）采购总表该房源记录；该表优先于旧案例、房源广告家具和个人审美。历史案例不能覆盖本次型号、数量、床型或实际尺寸。
- 每次新建模先把2D floor plan上传到 Floorplanner，再校准、建房间、确认尺寸，最后扩展整个 plan。已有同一任务的正确底图可以复用，先核实其楼层及校准状态，不重复上传或重建。
- 用户已授权本流程所需的 Floorplanner 上传、建模、保存、家具摆放及合理的补充布置；不逐项重复索取操作许可。房间尺寸确认是用户要求的设计检查点，应先提供可核对的成果。
- 飞书在此流程中作为只读依据；添加到 Floorplanner 的建议物品不自动写回采购表，也不下单、不把计划采购称为已购买。不改历史参考项目。付费升级或消耗未授权付费额度前，先完成可用的标准预览，说明具体费用或额度。

## 1. 定位房源与资料

先读 [references/sources.md](references/sources.md) 获取已知入口和使用限制。优先当前可用的连接器；没有相关连接器时使用已登录浏览器，并遵循当前浏览器工具文档。不能因没有专用 Floorplanner/飞书 API 就忽略已有网页渠道。

1. 核对门牌、街道、suburb、州、邮编、公寓号和楼层，避免同名街道或同楼其他户型。仅给地址也先查可取得的资料，不要求用户重复提供能找到的内容。
2. 找到同地址现有 Floorplanner 项目则先检查进度并续做；没有才新建。多个项目无法分辨时询问目标版本；保存变更前可创建明确命名的设计副本，保留用户已有成果。
3. 优先用户给的2D图；否则查该地址的 realestate.com.au 户型图，保留页面链接和原图。确认楼层数及现况，广告图与用户所述有出入时以用户说明为准。不能拿相似房源图代替。确实找不到时请求用户提供图，并继续整理可取得的尺寸、采购和案例资料。
4. 整理每个房间的对应关系、长宽、单位、尺寸口径和来源。通常室内尺寸指完成面之间净尺寸；口径不明且会影响建模时先问清。凹凸房间保留分段尺寸，不能将外包长宽当作完整矩形。
5. 读取飞书中该地址全部相关采购记录，包括尚未下单的有效计划；不能只看当前屏幕或当前被过滤的视图。按当前字段名读取物品名、型号/规格、数量、房源、图片/链接、备注、状态及房间分配。多房源共用记录只取本房源明确的分配量，不能把整行总量搬入。
6. 去重并识别取消、被替代、补货、备用库存及套装；保留未明确分配的问题。区分购买包数与实际件数，床架和床垫不要误做成两张床；运营备品和耗材不全部陈列。
7. 打开用户已有的、已布置完成的 Floorplanner 案例，挑户型或定位相近的几个参考配色、木色、沙发与床、灯具、地毯、挂画和摆件密度。记录实际查看的项目链接和观察；不要把尚未建好的项目当成熟风格案例。访问不到时说明未能参考，继续其余工作。

## 2. 先上传2D图并校准

- 在本房源项目使用当前界面的上传2D图或背景图入口；多层房源分别匹配底图和楼层。成功标准是编辑器内可见正确底图，不能只完成文件选择就声称已上传。
- 统一尺寸单位，明确区分 m、cm、mm。必要时校正底图方向，保持原始长宽比；不可用非等比拉伸冒充测量校准。
- 用用户已知长度及其对应端点设比例尺。若有另一方向或另一房间的已知尺寸，交叉核验，不能只校准一条边便宣称整图准确。
- 默认沿2D图纸实际墙体边缘按1:1真实尺度描建，先校准再描边，保持整体外轮廓、比例及各房间的相邻关系。用户说明尺寸已扣除衣柜时，按衣柜前沿至对面完成面的净空约束房间，衣柜占地另建；不能再次扣除衣柜，也不能把衣柜包含回已确认净尺寸。
- 尚未提供任何实测尺寸时，先完成底图导入和资料整理，集中请求必要的房间尺寸。可按广告标注设置临时比例，但必须标为未实测校准；收到用户尺寸后重新校准，不能带着临时比例直接宣称精确完成。
- 图像比例与用户多处尺寸无法同时吻合时，底图只保留为结构参考，各房间按实测值单独约束。不能为了贴合广告图，缩放或改写用户尺寸。
- 自动识别/描图结果只算起稿，需逐房间核对；不要绕过底图流程直接生成一张外观近似的3D图片。

## 3. 先建房间、核对尺寸，再扩展全屋

先建立用户已提供尺寸的房间，数值输入墙体/房间几何，处理墙厚、共享墙和内外墙口径。不要只改尺寸标注文本；自动标注、手工尺寸线与实际几何可能不同，必须检查实际墙面间净距。

向用户提供当前房间2D截图或项目视图，并给出简明核对表：

| 房间/楼层 | 用户尺寸与口径 | 模型实际净尺寸 | 差异或缺失 | 确认状态 |
|---|---|---|---|---|

所有已提供尺寸应在模型支持的精度内匹配；有舍入差异须说明具体值，不擅定较宽容差。对缺少尺寸的部位写“暂估/待确认”，不冒充实测。

**将这一版房间及尺寸给用户确认后，再延伸到整个 plan。** 若用户已经确认过同一版房间及尺寸，沿用确认，不再问一遍。等待时可以继续读采购表、参考案例和整理素材；不得把尚未确认当作已批准。问的是具体房间、尺寸或冲突，不是空泛的“能否继续”。

确认后按底图的相邻关系和用户补充信息，补齐其余房间、走廊、厨房、卫生间、门窗、固定柜体、楼梯及相关室外空间。墙厚、层高、门窗宽高、窗台高度等未提供时采用有依据的暂估并记录；需要影响家具能否放下的关键尺寸时先核实。

每次调整共享墙或总体轮廓后，重新读回受影响的已确认房间尺寸，防止延伸全屋时改变原房间。核查墙体闭合、共享墙无重复、楼层连接、门的方向和开合；局部净尺寸与外轮廓不能同时满足时列出冲突，不暗改用户数据。

## 4. 按飞书采购布置，参考历史案例搭配

先放决定占地的大件，再摆灯具、地毯、窗帘和装饰。以真实物品的宽×深×高设置模型；床架使用外形尺寸，不能用床垫尺寸冒充床架占地。优先查飞书记录、对应商品链接和用户补充参数。

建立可追溯对应：飞书采购编号/记录 → 物品及本房源数量 → 安放房间 → Floorplanner 对应模型及尺寸 → 匹配情况。

- 库中没有完全同款时，选外形、材质、颜色接近的模型并按真实尺寸调整；标注“示意替代”，不能称为同款。不能精确调整时说明模型与实物的差异。
- 不通过缩小家具、扩大已确认房间或改写采购规格来消除碰撞。放不下先调整布局；仍有冲突则说明具体物品、净距和建议方案。
- 查明采购清单中已选物品与历史风格的关系，尽量沿用案例的搭配方式。清单已有的挂画、地毯等先落实，再考虑补充。
- 检查通行、门扇、衣柜/抽屉/电器开门、床侧与餐椅使用空间，以及物件的实际支撑高度。未核实的净距不声称满足法规。
- 固定结构以实际房源为准；不把移动墙体、改门窗或拆改当作普通软装调整。

## 5. 可以主动添加，但记录清楚

用户允许为效果和实用性直接在 Floorplanner 加入合适的物品，例如落地灯、绿植、抱枕、挂画、地毯或边几；选品应符合已有案例、空间尺寸及本次配置，不必逐件先问。

随操作记录实际新增、移动、替代和移除的内容，最终只汇报保留在方案内的结果：物品、数量、房间/位置、尺寸（影响占地时）、原因，以及是否飞书原清单之外。飞书已有家具仅因库中无同款而选示意模型，属于“模型替代”，不计成额外采购。

主要采购家具的换款、删减或床位数变化若没有用户指示，保留原清单方案，将替代建议放在单独方案或待决清单中，不默默覆盖。纯布局微调可以直接完成，并简述关键变化。新增仅代表设计建议，不表示已采购或已获购买批准。

## 6. 验收、保存和交付

- 几何：将已确认尺寸与模型实际尺寸逐项对照；区分实测、广告参考及暂估，特别检查家具布置过程中有无误移墙体。
- 配置：对照该地址采购表核对主要家具、数量和房间分配，明确未能放入的物品、示意替代及备用/耗材的处理。
- 视觉：实际查看2D全图、3D全屋视角和关键房间视角，修正穿墙、悬浮、遮门及明显拥堵。不得只凭缩略图宣布检查完成。
- 保存：确认平台显示已保存，或保存后重新打开核实。按可用权限提供2D尺寸图、3D总览及必要房间视图；标准截图也可交付，说明与正式导出的区别。文件确实生成并检查过才能称已导出。
- 交付中文结果：项目链接；已确认尺寸及仍暂估的关键部位；飞书清单落实情况；额外添加表（物品、数量、位置、原因）；模型替代或重要布局调整。没有额外添加时明确写“本次未添加飞书清单外物品”。

任务中断时，在当前任务的工作文件中保存地址、项目链接/楼层/方案、底图来源、尺寸对照和用户已确认的版本、采购读取日期、实际查看的案例、额外添加记录及下一步。恢复时先核对项目当前状态，不重复创建或重复摆放。房源运行资料不要混写进通用技能。
