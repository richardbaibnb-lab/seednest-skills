# 房源政策与截图基线

本文件来自用户 2026-09-23 提供的教学截图。它们是执行该流程时的初始参考；目标 Airbnb 已核实的专属设施/政策或用户后续要求优先。截图未展示的字段不要自行补成“全房源统一规则”。

入口：**Property → Property policies**。先看当前值，已一致的保留；需要修改的编辑并保存，回到卡片核对结果。

## Children / Extra bed & crib options（图 04–06）

教学示例：

- Children of all ages are allowed；17 岁及以下免费（页面背景已存在的政策，先核对目标）。
- 对应出租单元 Cribs = **1**，Extra beds = **0**。
- Crib Policies → Add：年龄 From **0** through **2**，Price = **Free**。
- Crib availability = **Always available**。

先核实目标 Airbnb/用户资料确实提供婴儿床。确认固定提供时可采用示例 1 张、0–2 岁免费且 Always available；若只能申请、数量不同或明确无婴儿床，按实际条件填写，不能借用示例宣称随时有床。Extra beds 指额外加床，不是原有床位总数，不要填成卧室内现有床的数量。

## Guest Payment Options（图 07）

截图选中下列卡种，**Cash 未选**，**Collect credit card CVC for new reservations = Yes**：

American Express、Euro/Mastercard、JCB、Discover、UnionPay credit card、Visa、Diners Club、Maestro、Eftpos、Bankcard。

按教学设置选择页面当前仍提供且目标可接受的对应卡种，不因为有新的未见选项就全选。Guest Payment Options 与 Payments by Booking.com 激活是独立设置；保存卡种不代表平台已代收，也不等于操作客人的信用卡或收取费用。

## Internet and parking（图 08）

示例 Internet：**Yes, free / Wi-Fi**；截图 Connection location 为 **Public areas**。

网络是否免费及覆盖范围仍要核实目标房源。Public areas 是该张截图所示值，不是所有整套住宅的固定规则；若目标证据支持整套/全部房间覆盖，按当前页面对应选项填写，不能为照抄截图制造错误覆盖描述。停车截图没有给出明确参数，按实际设施核对。

## Guest Information / Check-in & Check-out（图 09）

| 字段 | 教学示例 |
|---|---|
| Check-in from | 4:00 PM（16:00） |
| Check-in end | 未设置 |
| Check-out start | 未设置 |
| Check-out until | 10:00 AM |
| 24-Hour Check-in / Check-out | 均未勾选 |
| Ask estimated arrival time in advance | No |
| Can guests book without address details? | Yes（不要求地址） |
| Can guests book without a phone number? | No（要求电话） |
| Is there an age limit to check in? | No |
| Is there a curfew? | No |

注意“without”问题的 Yes/No 含义。目标 Airbnb 入住退房时间或明确规则不同时按已核实规则填写。没有宵禁与没有安静时段是不同事情；不要据此删除 House Rules 的 quiet hours。不要把“未设置结束时间”转换为 24 小时入住。

## 30+ night stays（图 10–11）

教学示例：接受 **超过 30 晚 = Yes**，最大 **90 nights**，Save。保存后若出现 “Attract long-stay guests with a monthly rate plan”，点 **Close**；这一步不创建新的月租 rate plan，不修改折扣。

若目标 Airbnb 或用户已明确有更短最长入住限制，先保留该限制并记录冲突，不能为了跟随教学示例放宽。

## 不从页面背景复制的内容

- 示例的 AUD 240 清洁费及其计费方式属于示例房源。
- Key pick-up 背景含通过 Airbnb 收取入住说明的文字，不能原样成为 Booking 客人的指引。若另有授权编辑此项，先取得目标的正确渠道和实际开门方式。
- Damage policy、House Rules、Smart Flex、Booking method 等页面背景内容不是此次截图逐项设置的证据；只在本次任务要求或明确核实需要时处理，不用参考房源覆盖目标已有正确内容。
