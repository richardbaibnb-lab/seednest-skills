# 判断与运行记录

## 长期合作判断例子

- 可录入：同一清洁工在两个不同清洁日期为同一房源开票；邮件说明“weekly lawn mowing”；服务协议写明 ongoing/monthly service。
- 不可直接录入：首次报价、一次紧急开锁、一次性家具搬运、只出现一次且没有持续安排的维修账单。
- 待确认：同一公司出现两张附件，但两张是同一发票的副本；姓名相同但手机号不同；账单没有 service address，邮件也不能明确对应房源。

## 证据优先级

1. 服务协议、已确认的定期安排、邮件正文中的明确陈述；
2. 不同日期的已完成服务或发票；
3. 邮件签名、发件地址、附件抬头中的联系方式；
4. 文件名和邮件主题只能作为线索，不能单独证明房源或长期关系。

## 周度结果格式

- 时间窗口：开始时间—结束时间（含时区）
- 已检查：service 邮箱、clean 邮箱、本地对应日期文件夹
- 新增：联系人｜房源｜岗位类型｜关键联系方式｜长期证据
- 补全：联系人｜房源｜补全字段｜证据
- 跳过重复：联系人｜匹配依据
- 待确认/冲突：候选｜问题｜需要用户确认的最小信息
- 状态：成功并推进截止点，或失败且未推进截止点
