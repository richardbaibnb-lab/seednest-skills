# Setup-入住手册制作

固定顺序：**飞书完成完整图文手册 → 从飞书下载 PDF → 原样上传 pdfFiller**。飞书是编辑与定稿位置，pdfFiller 只用于上传存放。用户每次提供地址及该房源注意事项。

只要求维护技能时，不把示例地址当成真实制作任务。制作任务中直接完成已授权的查询、登录、编辑、下载、上传和归档，不逐步重复请求许可；不向客人或同事发送，不改变分享权限。

## 入口与资料保护

- 公开房源：[realestate.com.au](https://www.realestate.com.au/)，按包含单元号的完整地址查询。
- 飞书云盘「自管房源」或「代管房源」→ 本房源地址目录；已有本次草稿则续做，避免重复。
- [pdfFiller](https://www.pdffiller.com/) 账户在飞书「SEEDNEST民宿总表」→「账户密码」→「Airbnb运营账户密码」，匹配 pdffiller.com 记录，不依赖行号。已有登录时核对账户；验证码阻碍时让用户协助。
- 登录密码仅用于该平台登录，不写入技能、手册、记录和回复，不保存整张密码表为素材。客用 Wi-Fi 和锁盒信息可写入本房源受控手册；路由器管理员密码、设备序列号不进入客人版。
- 优先正式连接器，否则使用已登录网页及当前浏览器工具；浏览器操作前读取相应 computer-use 技能和工具文档。

## 1. 核对房源及完整历史参考

1. 查询准确 realestate 房源页，核对地址、物业类型和公开基本信息，保留链接。广告不证明当前床位、门禁、停车权限或运营政策。
2. 在飞书确认本房源资料、管理类型和目录。用户本次明确说明优先于旧资料；写入归属有冲突时先厘清。
3. 同时匹配物业和管理类型：公寓参考公寓，house 参考 house，自管参考自管，代管参考代管。同类优先同楼/同区域、取钥匙及停车方式近似、完整且较新的手册。实际阅读全文，不能只参考封面或入住路线。
4. 飞书历史手册为主要参考；pdfFiller 历史 PDF 可只读参考，不在那里复制编辑新手册。记录选择理由和链接。没有同类时说明差异，必要时询问参考选择，同时继续整理已知资料。
5. 整理事实与来源，集中处理实际缺项。用户明确允许某项沿用其他房源时照做，例如入住退房时间；不要要求重复提供已有资料。

## 2. 在飞书完成完整图文手册

在正确房源文件夹建立或续填文档，客人版标题 **完整地址 Check-in Guide**。保留单元号和在线标题的斜杠。按用户最新偏好，客人版标题、正文、图注及导出文件名全部使用英文，不出现中文；沿用历史手册品牌、完整章节及实用表达。

- 用户要求整体格式和措辞贴近过往 guide：优先保留所选完整历史手册的欢迎语、编号章节、粗体标签及固定规则表达，只替换房源事实和已确认政策；不要自行重写为不同结构的简版。House 历史参考常用七章为 Check-In Instructions、House Rules、Emergency Contacts、Local Recommendations、Appliance Use、Check-Out Procedure、Penalties for Rule Violation。
- 智能锁入住章节每次须直接列出本房源已确认可用的客用 PIN，并附用户指定或确认可沿用的对应门锁操作照片；不能仅写“PIN sent in your arrival message”。用户已确认其 house 使用的四组常用密码均可用，每次制作手册从用户提供的四组中随机选一组，只写这一组，不必重复询问。沿用此规则时从当前授权对话或房源受控资料取得实际码值；门禁码不保存到技能或工作记录。其他未确认的候选密码仍先核对。

按适用性覆盖：

| 章节 | 核对重点 |
|---|---|
| 欢迎与入住概览 | 地址、入住时间、关键先后顺序 |
| 取钥匙与正门进屋 | 信箱/锁盒、密码操作、门禁卡、入口、走廊和房门图文步骤 |
| 停车与回房 | 遥控器取用顺序、入口、专属车位、驾驶路线、电梯楼层、出电梯方向 |
| Wi-Fi | 精确名称及密码，保留大小写和前导零 |
| 住宿须知 | 适用的历史通用要求、本房源注意事项，不新增未经确认的罚款、取消政策或限制 |
| 紧急与住宿联系 | 正确紧急号码、适用于该地址的就医信息、现有预订联系渠道，不抄旧房源专属电话 |
| 周边生活 | 本房源实际周边地点及当前官方信息，不编距离或营业时间 |
| 设备与日常使用 | 适用的空调/供暖节能、清洁垃圾及设备说明，不编型号、设施权限 |
| 退房与归还 | 时间、车辆移出顺序、钥匙/卡/遥控器去向、关窗关门关电器 |

完整不等于照搬所有旧事实。旧地址、密码、车位、地图、照片、联系人、二维码均需替换或移除。收费条款仅在已确认适用时写入，否则引用预订已有条款，不新增金额。

- 真实照片按动作顺序放在对应文字附近，清楚标注，保留有用箭头；不能只放链接或留待插图，不虚构路线或设备图片。
- 优先手机阅读：短段落、清楚步骤、一致的图片宽度及紧凑留白。在飞书中缩小图片，竖向钥匙/遥控器图明显小于路线横图。不可因图片过大而单独占一页，也不可让说明与图片分页脱节；以实际导出逐页检查为准，不以编辑器外观代替验收。
- 所有截图黑边均需去掉，优先在飞书图片裁切中完成，保留门牌、箭头、车位和操作位置。最终交付是完整静态 PDF；不为在线交互额外做图片绑定，清楚的普通图文说明即可。裁切后重新检查导出尺寸与分页。
- 两种到达路径分别说明，核对取遥控器、停车、回房及退房形成可执行顺序。
- 按钮对应不确定且不影响说明时，用准确的功能描述，不猜按钮作用；关键路线缺项则保存草稿并集中询问。
- 客人版不残留内部制作说明、待补充、模板旧值和清洁团队内部流程。内部待办留在工作记录。

## 3. 从飞书导出并检查 PDF

1. 确认飞书完整正文与图片已保存，通过飞书下载/导出 PDF 功能取得文件。
2. **不要以本地重新排版生成的 PDF 替代飞书导出，不先编辑 pdfFiller 再回填飞书。** 排版问题回飞书修正后重新导出。
3. 文件名为完整地址加 Check-in Guide.pdf，全英文。本地非法字符可替换，在线显示尽量保留地址原样。
4. 按 PDF 技能逐页渲染检查截断、空白页、过大图片、分页、清晰度、编号、路线、旧地址及草稿提示，核对所有用户注意事项。

## 4. pdfFiller 只上传原文件

1. 在正确账户将飞书直接导出的最终 PDF 作为独立新文件上传，不合并旧模板、不加水印、不改文字、图片或页序。
2. 自动进入编辑器时只完成保存/Done 等上传收尾，不编辑内容。记录最终文件链接。
3. 检查上传结果、名称、页数与内容；状态不明确先查列表，避免重复。旧误建副本不能充当最终版本，可明确重命名区分。
4. 后续修订仍回飞书编辑、重新导出、上传对应新版，保持一致；不静默覆盖别人已有的不同成品版本。

## 5. 完成及续做

- 核对飞书父目录、标题、完整正文图片，最终 PDF 与 pdfFiller 上传内容一致。点击上传不等于完成。
- 简洁中文告知结果，提供飞书和 pdfFiller 文件链接及适用下载文件，不在聊天摘要复述密码。
- 导出或上传未完成时明确具体剩余步骤，不称全部完成。
- 工作记录保留地址、类型、管理方式、来源/参考、目录/文档链接、导出文件来源、pdfFiller 文件链接和待办，不重复保存账号密码或门禁码。
