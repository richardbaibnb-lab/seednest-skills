# 员工接入说明

## 尚待完成

当前已完成技能入库。账号邀请、员工端安装、版本更新流程仍需配置和试跑。不要把“仓库已有文件”理解为“员工已经更新”。

## 接入顺序

1. 为指定员工授予这个私有仓库所需的访问权限，使用员工自己的 GitHub 账号。
2. 确认员工使用独立个人账号，还是同一个 ChatGPT 团队工作区；据此选择本机插件来源或工作区分发。
3. 配置插件来源，安装后在新聊天核对能发现全部 24 个技能。
4. 按岗位配置业务平台、邮箱连接、浏览器会话及文件位置；插件本身不提供这些权限。
5. 对照本机旧技能，确认团队版可用后停用重复旧副本。
6. 选一个低影响任务，完成一次新版本发布和员工更新的试跑。

## 配置入口

- 仓库：`https://github.com/richardbaibnb-lab/seednest-skills`
- 更新分支：`main`
- 插件来源名称：`seednest-team`
- 插件名称：`seednest-skills`
- 插件目录文件：`.agents/plugins/marketplace.json`

具备相应 Codex CLI 和私有仓库访问权限的本机，可用官方入口添加及刷新来源：

```text
codex plugin marketplace add richardbaibnb-lab/seednest-skills --ref main
codex plugin marketplace upgrade seednest-team
```

上述步骤管理插件来源；仍须在客户端安装、确认启用并验证实际加载。当前团队尚未执行这些步骤。官方工作区导入支持定期同步，独立本机的定时更新需另行配置。

## 本机依赖

- 业务流程涉及飞书、Breezeway、Guesty、Airbnb、Booking、QuickBooks、Qwilr、AirDNA、pdfFiller、邮箱等平台，应按员工岗位授权。
- 自定义邮箱只读工具及官方插件应另行配置；本仓库没有复制它们的服务程序或连接凭据。
- 部分技能含原电脑的绝对路径、历史工作文件位置和 Windows 字体路径；首次使用前映射到员工电脑。导入范围文档列出涉及的文件。
- 运行进度保留在各自工作环境中。例行检查、催办和消息通知不能因为安装技能而重复启动，先确认哪台电脑负责执行。
- 本次仅搬入既有技能，未改写它们已有的触发和业务规则。浏览器选择仍以当前用户指令与本机 AGENTS.md 为准。
