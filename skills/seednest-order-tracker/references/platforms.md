# Platform access guide

## Amazon Australia

Use the signed-in `Your Orders` page. Check `Not Yet Dispatched` first, then the relevant time period or order search. Read order details only when the list view does not establish shipment status, quantities, or delivery dates. Amazon may split one order into multiple shipments; track each shipment or line separately.

## 1688 and Taobao

Use signed-in buyer order lists and logistics-detail pages. Distinguish seller dispatch, domestic warehouse receipt, consolidated shipment, international transit, customs, and final delivery. Do not translate an intermediate warehouse receipt into delivery to the Australian property.

## Other Australian retailers

Prefer the retailer account's order-history page. If the retailer provides only tracking links, use the named carrier's official tracking result. When guest checkout prevents account lookup, use order-confirmation email only if the user has placed email in scope.

### Sheridan Outlet

Use `https://www.sheridanoutlet.com.au/`, not the separate Sheridan main site. The signed-in order-history page is `/sales/order/history/`; use each order's `View Order` page or the site's `Track Your Order` form when fulfillment details are needed.

## Unsupported or blocked access

If authentication, OTP, CAPTCHA, or bot protection blocks access, stop that platform and ask the user to complete the interactive step. Continue checking other platforms that remain accessible. Never bypass access controls or infer delivery from an inaccessible page.
