# Chrome 任务连接与恢复

## 适用范围

- 用户明确指定 Chrome，或本任务已有使用 Chrome 的授权时，先执行本流程，再执行对应业务技能。沿用会话内已经验证成功的连接，不重复初始化。
- 未指定浏览器时，遵循全局默认内置浏览器偏好。本技能不把普通网页任务改为 Chrome。
- 当前工具文档决定可用 API 和具体恢复限制。不得把这里的经验当成绕过系统停止、拒绝访问或其他安全限制的授权。

## 成功路径

1. **使用官方入口。** 通过官方 Chrome 扩展和当前受支持的浏览器工具连接。首次调用严格按工具文档选择入口：已有标签页引用就获取该标签页；用户要求打开新网址就使用指定浏览器的创建入口；确实需要浏览器清单时才读取清单。不要强制在所有入口之前增加 `getBrowser`，不要硬编码浏览器 ID 或标签页 ID。
2. **复用正确配置。** 优先使用当前任务已有的 Chrome 绑定及目标标签页；多账号时按用户指定账号选择。仅看见 Chrome、扩展或浏览器清单不算连接验收通过。不要读取 Cookie、令牌或复制登录资料到其他浏览器。
3. **实际读取目标页面。** 通过受支持的页面读取接口取得实际网址和页面内容，核对目标站点及必要的账号或房源身份。只有这一步成功后，才开始业务修改。连接正常、网站登录正常、业务完成是三个不同的验收结果。
4. **明确的初始化失败才有限重试。** 若返回精确错误 `Unable to load browser request-header policy. Retry the browser command.`，按下节处理。其他错误先按当前工具的具体说明分类，不能套用此重试。
5. **保持成功连接。** 后续任务步骤继续复用同一工具运行环境和浏览器绑定。不要每一步重新创建连接、重置运行环境、重开 Chrome 或新建登录页。每次提交后依据页面结果验收业务操作。

## request-header policy 恢复

此错误发生在浏览器工具初始化阶段；它本身不说明网站已退出登录。

| 状态 | 下一步 |
| --- | --- |
| 首次出现上述明确允许重试的错误 | 保留同一运行环境、浏览器绑定及已知标签页，等待约 2 秒，重试初始化或只读请求一次。 |
| 第一次重试仍是同一错误 | 如当前工具没有更严格限制，等待约 10 秒，进行最后一次初始化或只读重试。 |
| 成功返回浏览器清单或绑定 | 继续实际读取目标页面；不能提前报告连接已经可用于业务。 |
| 已经读到页面 | 恢复当前任务，保留连接；不要为了“再确认”重置运行环境。 |
| 两次追加重试仍失败 | 停止这一轮重试，进入官方诊断，不无限循环。 |

- 重试之间禁止重置工具运行环境、重新导入后端、切换控制通道或重装扩展。受工具文档中更严格的限制约束。
- 仅重复明确可重试的初始化或只读请求。创建标签页失败且没有返回标签页 ID 时，先按受支持的只读入口恢复；恢复后检查原标签页是否已创建，避免盲目重复创建。
- 导航超时但已返回标签页 ID：获取并读取该标签页，判断真实状态；不要直接再开页面或再次启动登录。
- 提交、付款、发送消息、发送验证码、修改房源等操作超时或结果不明时，先读取实际结果；本流程绝不自动重放这些操作。
- 遇到访问被拒绝、系统停止、用户中止或安全拦截，立即遵守停止要求。不得以重试、切换到桌面控制或另一工具绕过。

## 重试后仍失败

1. 按当前官方浏览器工具的诊断文档检查 Chrome 是否运行、目标 Chrome 配置是否启用官方扩展、官方本机连接组件是否正常。优先使用插件自带的只读诊断程序；不要假定历史版本路径仍有效。
2. 分别记录：初始化配置加载失败、扩展与本机连接失败、目标页面访问失败、网站登录失效。只在实际读取网站页面后判断其登录状态，不因初始化错误要求重新登录或发送验证码。
3. 扩展及连接组件正常时，不反复重装它们，也不修改请求头策略、远程配置开关、浏览器产品代码或安全校验来求成功。网络原因需要独立证据，不能仅凭普通网址探测结果推断真实配置请求失败原因。
4. 用户已指定 Chrome 时，不自行切换内置浏览器或 Windows 桌面控制；需要更换浏览器时，说明具体失败原因并取得用户同意。已有授权适用时不要重复询问。
5. 汇报本次实际失败阶段、已尝试次数及仍需解决的问题。需要官方支持时准备简洁诊断信息；未经授权不发送反馈、日志或其他聊天消息。

## 已验证范围与维护

- 2026-10-04，本机同一 Codex 进程、同一聊天中，四轮全新的浏览器工具运行环境均最终读取到公开页面；一轮直接成功，三轮分别需要一次、两次、一次重试。第四轮实际读取了官方 Chrome 扩展文档页面。
- 这些结果验证了有限重试的恢复路径；没有验证新聊天、整个应用重启、所有网站或长期首次连接成功。不要宣称永久修复或保证每次成功。
- 独立运行环境重建仅用于用户请求的可靠性测试，并且在上一轮完成后进行；不能用作错误恢复或绕过限制。
- 本技能由本机全局 `AGENTS.md` 接入所有已选择 Chrome 的任务。其他电脑需另行部署；已运行的其他聊天不能假定立即刷新了规则。
- 工具升级后按当前文档执行；若用户要求验收，重新做真实页面读取测试并记录次数、是否重试和测试边界。
