# SEEDNEST PDF品牌样式

用户2026-09-09指定，今后采购PDF带新版logo，并参考其202604-202607 Roseberry业主报告。此文件仅保存视觉规范，不复用参考报告中的房东、住客或财务数据。

- 必须使用技能内 `assets/seednest-logo.png` 原图；保持比例，不重新生成、重绘、拉伸或改色。封面有明显圆形logo，续页有小圆形logo；在PDF中圆形裁切、细白描边，保留完整图案和SEEDNEST字样。
- A4竖版，白底，深绿色页眉（约#185532），白色粗体标题，右侧圆角浅绿信息卡；logo自带深绿底与金色图案，保留原貌。
- 正文无衬线中文字体（Microsoft YaHei），深蓝灰文字（#233044），次要信息灰蓝（#718096）。分区标题配短绿色竖线（#22C55E）。
- 表格使用浅灰表头、细浅灰分隔线、充足内边距；金额靠右，合计用浅绿底或绿色文字突出。避免大面积密集深色表头。
- 总预算用深藏蓝汇总条（#101827）和亮绿色金额（#4ADE80）；分开显示商品、费用暂列和预备金。
- 红色用于真实负数/扣款语义，不能把采购金额全刷红套用财务支出表。
- 页脚采用SEEDNEST Property Management、简短说明和页码。保持少量英文辅助标签，主体中文。
- 默认用 `scripts/render_branded_estimate.py`；旧renderer保留核算逻辑。禁止回退到纯文字SEEDNEST代替logo。

- 对外方案名用“标准版”；来源依据只作内部记录，不在PDF中显示。人工含清洁、摄影、组装布置和电工，均计入总预算。
