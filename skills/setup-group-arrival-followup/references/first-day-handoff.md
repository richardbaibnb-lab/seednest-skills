# 首日图与采购清单

## Floorplanner图与床型

读取最终方案后，交付**一张全屋平面总览图＋主要区域及各卧室的Walk广角截图**。主屋和附属空间放在同一张总览图里；多层房源可将楼层清楚分区排在同一张图内。不要再单独发送主屋、后屋和逐房间俯视图。

- 总览采用能看清房间位置、入口和床位的平面/正上方视角。直接在每个床位附近用醒目红字写床型，如`king / queen / double / bunk`，位置一眼可对应；文字避免遮住重要家具或通道。不能仅把床型写在群消息或独立图注中。多床房补数量；上下床用`bunk`，床垫规格另有确认时再补充。
- 主要区域（如客厅、餐厅、厨房）及各卧室使用**Walk / First Person**视角，镜头在房间内人的位置。参考用户示例：**Camera Height约165 cm，Field Of View约78°广角**，按房间大小微调以看清家具和摆放关系。每处优先一张充分展示的画面，需要才补另一角度；不用俯视、鸟瞰、屋顶切面图代替。卫生间、洗衣房、走廊、车库等不默认逐一截图，只有用户要求或确有布置说明需要时补。
- 用一致的房间名对应总览与Walk截图。取景覆盖主要家具、床头朝向、相邻柜子和通道，不隔墙拍摄或只截家具局部；截图来自真实项目，只调整观看角度，不改模型或覆盖用户保存的方案。
- 床型以用户确认的方案、采购表具体规格、订单/发票为依据；未下单设计不能写成已经购买。`King / Queen / Double / Single / King Single / Bunk`按真实配置标注。仅在有实际商品数据时追加厘米尺寸；床架外尺寸与床垫尺寸分别说明，不套通用尺寸猜测。
- 保留真实原图，标注时只添加必要文字，不重绘布局、床或收货事实。若需修改图像像素，按当前图像工具规则处理，逐一核对标注与原图相同位置。
- 关键床型不明或模型与已买家具冲突时，先列具体冲突给用户，不以猜测标注的图做正式首日交底。非关键未采购装饰如仍在模型中，图注注明“设计示意，尚未采购”；准备采购项仍按下述规则纳入全量清单。
- 发群前检查没有其他房源、账号菜单、通知弹窗或无关窗口；示例中的通知不是交付内容。尽量收起遮挡画面的控制面板，缩略图不作为清晰度验收。不要发付费升级请求或使用未经授权的付费导出。

## Excel：只留五列

先按准确房源过滤，读取该房源本次setup的全部采购物品行。清单用于让线下人员知道预计有哪些物品，包括准备下单和已下单项目；不要按购买进度筛选，也不要只导出当前屏幕可见几行。

- 包含已下单、未开始、准备下单、运输中、部分或全部到货的物品。**仅排除购买量明确为0的物品**，0表示本次setup不需要购买；不能把0视为数量异常，也不能仅因未下单、缺发票、取消或退款状态而漏掉仍有本次需求数量的物品。纯汇总父行不重复作为物品列入。
- 数量空白或未知不等于0：保留该行，在购买量写“待确认”，并在内部记录源值为空；不猜数量、不改飞书原值。其他非零数量及单位按本次房源需求原值保留。
- setup发票用于核对采购事实、规格和后续到货匹配，不作为进入全量清单的门槛。表与发票的下单状态差异只记入内部差异表，不因此增删已有非零需求行或自动修改购买进度。缺少采购编号的列为待核对，不伪造编号或静默补新行。
- 从读取/导出的源数据生成**干净的新工作簿**，只写下列列和值。不能仅隐藏多余列或工作表，不能保留原始表、隐藏数据、批注、外部链接或带出价格的公式。

| 输出列（固定顺序） | 数据规则 |
|---|---|
| 编号 | 原采购编号，以文本保存前导零；缺编号不重编号代替 |
| 中文 | 对应中文物品名，保留辨认规格所需文字 |
| 英文 | 对应英文物品名；缺失可作忠实翻译，不补来源没有的型号/规格 |
| 购买量 | 本房源本次需求/购买数量及原单位，包括准备下单数量；空白写“待确认”；多房源共用行只取明确分配量 |
| 所属分类 | 现有分类原值，不自行重分 |

不包含价格、金额、供应商、购买链接、订单号、发票附件、下单/到货状态、内部备注等额外列。题名/页眉可注明本房源和导出日期，这不增加数据列。

区分购买量、每包装物品数与总件数；例如买2包每包6个，购买量保留`2包`，不能悄悄替成12或2个。床架与床垫若是两条有效采购记录分别保留，不合并成一条“床”。同商品不同规格/不同采购编号不能粗暴去重。按所属分类整理，组内保留源编号及稳定顺序。

## 转PDF并发送

1. 保存`房源简称_setup全量采购清单_YYYYMMDD.xlsx`；更新已有交付文件时可沿用中性的稳定文件名。回读核对五列、非零需求行完整性、所有0数量项目均已排除、空白数量仍保留、编号及各行购买量。确保不是指向完整源表的另存副本。
2. 从这份净化后的Excel内容转换为同名PDF；直接转换不可用时，重新读取此Excel的五列值排版生成PDF，确保两份内容一致，不从另一份旧清单生成。
3. 用适合中英文的字体，重复表头，长名称换行，按宽度选横向或纵向；可以跨多页，不能强行缩为一页造成无法阅读。加房源、日期与页码，页内不增加其他数据列。
4. 渲染并检查每页无乱码、截断、错行、空白页，核对PDF的物品数、编号、规格和数量与Excel一致。价格等排除字段不能通过页眉、备注或隐藏内容泄露。
5. 将标床型的单张平面图、主要区域及卧室Walk广角截图和PDF发送到已核实群。先给简短说明“清单包含准备下单和已下单的全部本次所需物品，数量0的已排除，不代表全部已下单或已到货。请按房间图摆放；收到货物后在群内发照片，并注明物品/编号、数量、放置位置；缺件或损坏请一起说明”，不虚构采购状态或人员承诺。
6. Floorplanner截图直接作为图片发群，确保线下人员可在会话内查看；不要只发链接或把截图藏在PDF/压缩包里。采购清单只发PDF，**不发Excel**。观察图片、附件和消息确已出现在正确会话且没有发送失败标记，记录消息ID/时间和文件版本。按用户界面能确认的范围记录“已发送”，不无依据写成“对方已阅读”。
7. 用户明确本次自行发送图片时，记录“用户接手发送”，移除对应自动补发待办，旧版图片保留为已替代资料。不要为了补发再次操作微信，也不要将用户打算发送误记为已发送。日后可在已获准的群消息检查中核对实际结果，但不自动重发。

Excel、PDF和已核实的图保留在本任务输出目录。若群发送受阻，交付已准备的文件并记录未发送部分，不能用本地文件存在冒充群内交底完成。
